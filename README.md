# WebSocketChatRoom

这是一个基于 Vue.js (Vue 2)、Node.js 和 WebSocket 技术构建的桌面端在线聊天室应用。本项目旨在提供一个功能完善的实时通讯平台，尽管用户界面设计简洁，但核心聊天功能已全面实现并稳定运行。

## 项目特性

- **实时通讯**: 利用 WebSocket 技术实现消息的即时发送与接收。
- **桌面端应用**: 专为 PC 端用户设计，提供流畅的聊天体验。
- **简洁高效**: 专注于核心聊天功能，界面直观，易于使用。

## 技术栈

- **前端**: Vue.js 2, Element UI, View Design
- **后端**: Node.js, WebSocket (通过 `ws` 库实现)

## 快速开始

(此处应包含项目的安装、配置和运行指南，例如：)

1. 克隆仓库:
   ```bash
   git clone https://github.com/Creator12333/WebSocketChatRoom.git
   cd WebSocketChatRoom
   ```
2. 安装依赖:
   ```bash
   # 前端依赖
   npm install
   # 后端依赖 (如果后端有独立的 package.json，则需要进入 server 目录安装)
   # cd server
   # npm install
   # cd ..
   ```
3. 运行项目:
   ```bash
   # 启动后端服务
   node server/index.js # 假设后端入口文件为 server/index.js
   # 启动前端开发服务器
   npm run serve
   ```
